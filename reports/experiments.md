# Журнал экспериментов

Каждая запись: гипотеза, что изменили, число до и после, вывод. Из этого журнала
собирается исследовательский отчёт — критерии «Baseline и отправная точка» и
«Эксперименты и сравнения», 10 баллов рубрики.

Протокол валидации един для всех записей: из известных значений `primary_ndvi`
случайно скрывается 20 %, распределение по длине разрыва и месяцу сохраняется,
разбиение GroupKFold по `anon_polygon_id` — целые поля вне обучения.
Метрика — RMSE по скрытым точкам, зерно 42.

---

## E00. Разведка данных

**Что делали.** Разбор выданного `private_features.csv` до написания кода.

**Наблюдения.**

1. `primary_ndvi` — склейка трёх сенсоров по приоритету. Там, где доступен
   Sentinel-2, значение совпадает с `s2_ndvi` до последнего знака: проверено на
   7 815 строках, доля точных совпадений 1,000. Иначе берётся Landsat, иначе MODIS.
   Значение существует ровно тогда, когда доступен хотя бы один сенсор.
2. В контрольных строках замаскированы все признаки, кроме `anon_polygon_id`,
   `date` и `crop_type`. Опора возможна только на соседние наблюдения того же
   полигона, климатическую норму и календарь.
3. Разрывы короткие: медиана расстояния до ближайшего известного значения — 3 дня
   с каждой стороны, 75-й процентиль 6 дней, максимум 189. У 99,2 % контрольных
   точек соседи есть с обеих сторон, экстраполяция почти не нужна.
4. Шум наблюдения велик: стандартное отклонение разности между соседними днями
   0,093, внутри одного Sentinel-2 0,086. Значит собственный шум наблюдения
   около 0,07.
5. История неравномерна: 19 полигонов покрывают 2010–2025, остальные 59 — только
   сезон 2025. Климатическая норма по собственной истории доступна не всем.

**Вывод.** Основной источник ошибки — не разрывы, а шум наблюдения. Значит рычаг
не в точности интерполяции между двумя точками, а в сглаживании по окну.

## E01. Baseline и первое сравнение методов

**Гипотеза.** Ошибка baseline — это усреднение двух зашумлённых точек. Сглаживание
по окну из десятка наблюдений подавит шум сильнее.

**Условия.** 3 495 скрытых точек, 78 полигонов.

| Метод | RMSE | GapScore |
| --- | --- | --- |
| Среднее двух ближайших известных | 0,0907 | 2,8 |
| Линейная интерполяция по времени | 0,0894 | 3,2 |
| Скользящее среднее, окно 21 день | 0,0966 | 1,0 |
| Уиттекер, λ = 10 | 0,0916 | 2,5 |
| Уиттекер, λ = 100 | 0,0875 | 3,7 |
| Уиттекер, λ = 1000 | 0,0937 | 1,9 |
| Смесь Уиттекера λ = 100 и линейной, 50/50 | **0,0849** | **4,5** |

**Вывод.** Гипотеза подтверждена, но выигрыш ограничен. Скользящее среднее
проигрывает, потому что игнорирует расстояние по времени. Оптимум λ около 100:
меньше — недосглаживание, больше — срезается реальная сезонная динамика. Смесь
работает лучше обоих компонентов: Уиттекер даёт устойчивость на длинных разрывах,
линейная интерполяция — точность на коротких.

**Принято в работу.** Смесь 50/50 при λ = 100 — текущая конфигурация
`src/core/restore.py`, на ней сформирован первый `submission.csv`.

## Следующие шаги

- **E02.** Робастная очистка выбросов перед сглаживанием: в данных 28 значений
  вне диапазона от нуля до единицы, размах от −0,64 до 1,84.
- **E03.** Подбор λ отдельно по длине разрыва, а не единый для всего ряда.
- **E04.** Климатологический якорь: интерполировать отклонение от нормы, а не сам
  NDVI. Ожидаемый эффект в первую очередь на длинных разрывах.
- **E05.** LightGBM поверх предсказаний нескольких методов с контекстными
  признаками: расстояние до соседей, ширина окна, число наблюдений вокруг,
  климатическая норма и её разброс, число опорных лет, тип культуры, гармоники
  дня года, погода из соседних дат.
- **E06.** Фиксация лучшей конфигурации, стоп по времени.
