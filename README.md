# Фенолог

Веб-сервис мониторинга вегетационной динамики сельскохозяйственных территорий.
Космохакатон, кейс «Мониторинг вегетационной динамики».

> Владелец этого файла — Никита. Здесь пока заглушка: полная инструкция запуска
> появится вместе с сервисом. Требование рубрики — эксперт должен запустить
> решение по README без единой правки кода.

## Технический режим

```bash
pip install -r requirements.txt
python -m src.cli.batch_infer --input data/private_features.csv --output submission.csv
```

## Структура

```
src/contracts.py   контракт между слоем данных и доменным ядром
src/core/          восстановление ряда, климатическая норма, аномалии
src/ml/            признаки, обучение, инференс
src/cli/           batch-инференс
src/providers/     источники данных
src/api/           FastAPI
web/               интерфейс
reports/           журнал экспериментов и исследовательский отчёт
docs/              задания участникам
```

Правила работы над проектом — в `CLAUDE.md`. Задание Никите — в `docs/NIKITA.md`.
